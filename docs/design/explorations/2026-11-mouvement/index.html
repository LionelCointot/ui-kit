Votre système demande de réduire les animations : elles sont coupées sur cette page, comme dans le kit.

Mouvement : trois réglages à comparer

Les trois colonnes ont la même courbe de mouvement (cubic-bezier(0.2, 0, 0, 1)) et le même décalage entre cartes (50 ms). Elles ne diffèrent que par la durée et la distance de descente. Cliquez dans chaque colonne, ou rejouez.

Cascade

Réglage Standard pour le reste. Trois façons d'allonger la cascade de cartes : même courbe, descente de 8 px.

Déplacement

Seuls les déplacements prennent un ressort ; les fondus gardent cubic-bezier(0.2, 0, 0, 1). La durée dépend de la distance parcourue pour B et C. Cliquez sur Filtrer, sur un onglet ou sur un élément de navigation, ou rejouez.
