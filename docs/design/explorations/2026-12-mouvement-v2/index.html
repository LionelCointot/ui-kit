Même scène, deux vocabulaires de mouvement. Le mode A applique les tokens actuels du kit : courbe standard, cascade 350 ms, descente de 8 px, indicateur en 500 ms. Le mode B ajoute le vocabulaire v2 proposé : entrées en 600 ms en courbe expo-like, remplissages en 900 ms, dépassement léger sur les indicateurs, flash quand une valeur change. Seul le jeu de variables CSS change entre les deux modes — c'est la preuve que des tokens suffisent à tout. Les trois réglages calibrent la v2 ; les chiffres affichés sont des valeurs d'exemple.
